# English-to-French Neural Machine Translation (LSTM Encoder–Decoder)

An end-to-end Neural Machine Translation (NMT) system built with TensorFlow and Keras that translates English sentences into French using an **LSTM Encoder–Decoder** architecture trained on the **IWSLT 2017 (`en-fr`)** dataset.

## Architecture & Methodology

### 1. Subword Tokenization (BPE)
* **Byte-Pair Encoding (BPE):** Trained separate English and French BPE tokenizers (`vocab_size = 16,000`) across all `232,825` training pairs using Hugging Face `tokenizers`.
* **Normalization & Pre-tokenization:** Applies NFD Unicode normalization, lowercasing, accent stripping, and whitespace/punctuation splitting, with special tokens `["<PAD>", "<UNK>", "<SOS>", "<EOS>"]`.
* **Eliminating `<UNK>` Gaps:** Subword segmentation decomposes rare or compound words into known subword units rather than mapping them to `<UNK>`.

### 2. Data Preprocessing & Sequence Bucketing
* **Dataset:** IWSLT 2017 English–French (`213,088` complete sentence pairs retained for training and `793` pairs for validation after filtering sequences exceeding `MAX_LEN = 50`).
* **Source Sequence Reversal:** Source English token sequences are reversed (`[::-1]`) before encoding so the beginning of the English sentence sits closer to the initial decoding steps, reducing short-term dependency distance.
* **Dynamic Sequence Bucketing:** Uses `tf.data.Dataset.bucket_by_sequence_length` (`boundaries = [12, 20, 30, 40]`, `batch_sizes = [256, 256, 192, 128, 128]`) to group similar-length sequences together and minimize `<PAD>` computation overhead.

### 3. LSTM Encoder–Decoder Model (`model.py`)
* **Encoder:** Maps source token IDs into `384`-dimensional embeddings (`mask_zero=True`) and processes them with a `512`-unit LSTM layer (`dropout=0.2`), outputting the final hidden state and cell memory state $(h_T, c_T)$.
* **Decoder:** Initialized with the encoder's final states $(h_T, c_T)$, embeds shifted target French tokens (`<SOS>` + target sequence) into `384`-dimensional vectors (`mask_zero=True`), passes them through a `512`-unit LSTM (`dropout=0.2`, `return_sequences=True`), and projects outputs through a Dense layer over the `16,000`-token target vocabulary.

### 4. Training Strategy (`train.py`)
* **Teacher Forcing:** Feeds ground-truth target tokens shifted by `<SOS>` during training to predict target tokens ending with `<EOS>`.
* **Masked Loss:** Computes Sparse Categorical Cross-Entropy (`from_logits=True`) with a binary mask excluding `<PAD>` positions from loss and gradient updates.
* **Optimization:** Trained for `10` epochs using `Adam` (`initial_lr = 1e-3`) with L2-norm gradient clipping (`clipnorm = 1.0`) to prevent exploding gradients and automatic learning-rate decay on validation plateaus.

### 5. Inference & Decoding (`translate.py`)
* **Greedy Search:** Selects the single highest-probability token ($\arg\max$) at each time step until `<EOS>` or `MAX_LEN` is reached.
* **Beam Search:** Maintains the top $K = 5$ candidate hypotheses at every step and ranks sequences using length-normalized log-probabilities ($\text{score} / \text{length}^{\alpha}$ with $\alpha = 0.7$) to produce more fluent multi-word phrasing.

## Translation Evaluation (`ckpt-10`)

Sample translations generated by `translate.py` comparing **Greedy Search** and **Beam Search (`beam_width = 5`)**:

| Source (English) | Greedy Search (French) | Beam Search (French) |
| :--- | :--- | :--- |
| `Thank you so much.` | `merci beaucoup .` | `merci beaucoup .` |
| `How are you doing today?` | `comment faire aujourd ' hui ?` | `comment est - ce que vous faites aujourd ' hui ?` |
| `I work as a doctor, and my brother works as an engineer.` | `je travaille en tant que medecin , et j ' ai commence mon travail .` | `je travaille en tant que medecin , et j ' ai commence mon travail .` |
| `This is a very important problem.` | `c ' est un probleme tres important .` | `c ' est un probleme tres important .` |
| `We need to find a better solution for the future.` | `nous devons trouver une solution pour le futur .` | `nous devons trouver une solution pour le futur .` |

### Key Observations
* **Fluent Direct Translations:** Short and medium declarative sentences (`"Thank you so much."`, `"This is a very important problem."`, `"We need to find a better solution for the future."`) translate cleanly with accurate French grammar and vocabulary.
* **Beam Search Syntactic Gain:** On `"How are you doing today?"`, Greedy Search collapses into an infinitive fragment (`"comment faire aujourd ' hui ?"`), whereas Beam Search preserves the subject pronoun and interrogative phrasing (`"comment est - ce que vous faites aujourd ' hui ?"`).
* **Fixed-Vector Bottleneck on Multi-Clause Sentences:** On the two-clause sentence (`"I work as a doctor, and my brother works as an engineer."`), the model accurately translates the first clause (`"je travaille en tant que medecin"`), while the second clause shows the classic fixed-state bottleneck of non-attention Seq2Seq models where all source semantics are compressed into a single $(h_T, c_T)$ vector.

## Setup & Usage

### 1. Install Dependencies
```bash
pip install tensorflow "datasets==3.6.0" "huggingface-hub<1.0" tokenizers numpy
```

### 2. Train the Model
```bash
python train.py
```

### 3. Run Inference (Greedy & Beam Search)
```bash
python translate.py
```
